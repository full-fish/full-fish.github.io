#### **openssl 이란**

SSL과 TLS프로토콜의 개방형 소스구현

openssl을 이용하여 자체적으로 키를 생성할 수 있다.

#### **openssl 설치**

```javascript
brew update // 홈브루 최신상태 업데이트
brew search openssl // openssl 검색
brew install openssl1@1.1 // openssl 설치
```

#### **키 발급**

**개인키 만들기**

openssl에 들어간후

```angelscript
genrsa -aes256 -out rootca_private.key 2048
// 암호화 하지 않으려면 -aes256빼고 만들면 됨
```

**개인키로 공개키 만들기**

openssl에 들어간후

```autohotkey
rsa -in rootca_private.key -out rootca_public_key.pem -pubout
```

openssl에 접속했던 폴더에 공개키와 개인키가 만들어져있다
