**코드**

```javascript
function solution(arr) {
  let result = [];
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] !== arr[i - 1]) result.push(arr[i]);
  }
  return result;
}
```

**filter를 이용한 코드 (메모리면에서도 이익)**

```javascript
function solution(arr) {
  return arr.filter((ele, index) => ele != arr[index + 1]);
}
```
