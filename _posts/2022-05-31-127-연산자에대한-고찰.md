\*\*연산자는 거듭제곱을 해주는 연산자이다

2^50을 2\*\*50으로 쓸 수 있다.

나는 2\*\*50은

```javascript
let result = 1;
let base = 2;
for (let i = 0; i < 50; i++) {
  result *= base;
}
```

과 마찬가지로 50번 반복을 할 줄알았는데

```javascript
function pow(base, exponent) {
  let mul = 1n;
  while (exponent > 1n) {
    if (exponent % 2n === 0n) {
      base *= base;
      exponent /= 2n;
    } else {
      mul *= base;
      base *= base;
      exponent /= 2n;
    }
  }
  return base * mul;
}
```

3가지 경우에대해서

console.time()을 이용해서 시간을 재보았다

```javascript
console.time("pow");
let a = pow(2n, 1100000n);
console.timeEnd("pow");

console.time("**");
let b = 2n ** 1100000n;
console.timeEnd("**");

console.time("for");
let result = 1n;
let base = 2n;
for (let i = 0n; i < 1100000n; i++) {
  result *= base;
}
console.timeEnd("for");
```

결과

```html
pow: 3.253ms
**: 0.037ms
for: 11.483s
```

for가 압도적으로 많이 걸린다는것을 알 수 있다.

그런데 O(logN)으로 줄인 알고리즘보다 \*\*이 더 빠르다는것을 알 수 있다.
