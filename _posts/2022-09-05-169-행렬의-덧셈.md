**코드**

```javascript
function solution(arr1, arr2) {
  let result = [];
  for (let i = 0; i < arr1.length; i++) {
    let temp = [];
    for (let j = 0; j < arr1[i].length; j++) {
      temp.push(arr1[i][j] + arr2[i][j]);
    }
    result.push(temp);
  }
  return result;
}
```

임시 행렬을 만들어서 안에 넣는식으로 했다

**다른 사람 코드**

```javascript
function solution(arr1, arr2) {
  return arr1.map((a, i) => a.map((b, j) => b + arr2[i][j]));
}
```
