```javascript
// n이 양수여야함
function factorial(n) {
  return n !== 1 ? n * factorial(n - 1) : 1
}
```

위 코드에 비해서 아래 코드는 n이 0 일때, 한번 더 반복되지만 n이 0이라도 에러 안남

```javascript
// n이 0이상이여야 함
function factorial(n) {
  return n ? n * factorial(n - 1) : 1
}
```
