**코드**

```javascript
function solution(n) {
  let sum = 0;
  for (let i = 1; i <= Math.sqrt(n); i++) {
    if (n % i === 0) {
      sum += i;
      if (n / i != i) sum += n / i;
    }
  }
  return sum;
}
```

제곱근을 사용하여 시간복잡도를 줄였다
