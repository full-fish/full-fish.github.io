**코드**

```javascript
function solution(n) {
  return n
    .toString()
    .split("")
    .reverse()
    .map((ele) => parseInt(ele));
}
```

위의껀 문자로 변환해 푼 방법인데

**코드**

```javascript
function solution2(n) {
  var arr = [];

  do {
    arr.push(n % 10);
    n = Math.floor(n / 10);
  } while (n > 0);

  return arr;
}
```
