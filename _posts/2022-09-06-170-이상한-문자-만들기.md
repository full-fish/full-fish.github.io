**코드**

```javascript
function solution(s) {
  let answer = "";
  let wordIndex = 0;
  for (let i = 0; i < s.length; i++) {
    if (s[i] === " ") {
      wordIndex = -1;
      answer += s[i];
    } else if (wordIndex % 2 === 0) {
      answer += s[i].toUpperCase();
    } else answer += s[i].toLowerCase();
    wordIndex++;
  }
  return answer;
}
```

공백이 2개 이상있을 수 있으므로 따로 wordIndex 변수를 만들어서 공백에 대응함
