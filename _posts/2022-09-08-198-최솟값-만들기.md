**코드**

```javascript
function solution(A, B) {
  let result = 0;
  A = A.sort((a, b) => a - b);
  B = B.sort((a, b) => b - a);
  A.map((ele, index) => (result += ele * B[index]));
  // for (let i = 0; i < A.length; i++) {
  //   result += A[i] * B[i];
  // }
  return result;
}
```

처음에 for문으로 했다가 더 줄여보고싶어서 map으로 했는데

reduce로 하면 된다

```javascript
function solution(A,B){
    A.sort((a, b) => a - b)
    B.sort((a, b) => b - a)
    return A.reduce((total, val, idx) => total + val * B[idx], 0)
}
```
