**초기 코딩**

**function solution(num) {   
    var answer = '';   
    return answer;   
}**

**첫 아이디어**  
%로 나머지를 구해서 0이면 짝수 1이면 홀수

**나의 코드**  
function solution(num) {   
    var answer = '';   
    if(num %2 === 0){   
        answer = 'Even';   
    }   
    else{   
        answer = 'Odd'   
    }   
    return answer;  
}

**더 좋은** **코드**  
function solution(num) {  
    return num % 2 ? "Odd" : "Even";   
}
