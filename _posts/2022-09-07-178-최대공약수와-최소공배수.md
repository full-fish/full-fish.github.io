**코드**

```javascript
function solution(n, m) {
  return [gcd(n, m), lcm(n, m)];
}

function gcd(a, b) {
  return a % b ? gcd(b, a % b) : b;
}
function lcm(a, b) {
  return (a * b) / gcd(a, b);
}
```
