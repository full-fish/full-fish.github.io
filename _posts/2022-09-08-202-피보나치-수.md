**코드**

```javascript
function solution(n) {
  let fiboArr = [0, 1];
  for (let i = 2; i <= n; i++) {
    fiboArr.push((fiboArr[i - 1] % 1234567) + (fiboArr[i - 2] % 1234567));
  }
  return fiboArr[n]%1234567
}
```

처음에는 재귀적으로 풀었는데

런타임에러가 나길래

객체 메모리를 이용해서 더 빠르게 풀었는데도 런타임에러가 났다

객체 메모리를 이용하면 더 빠르긴 하지만 결국에는 O(2^n)만큼 계산해야하므로

결론적으로는 위 코드처럼 배열형태로 풀었다
