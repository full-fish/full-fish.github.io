**코드**

```javascript
function solution(s) {
  if (s.length === 4 || s.length === 6) {
    for (let i = 0; i < s.length; i++) {
      if (isNaN(parseInt(s[i]))) return false;
    }
    return true;
  } else return false;
}
```

parseInt()의 경우에

'a1'는 NaN이 나오지만

'1a'는 1이 나온다

Number의 경우

둘다 NaN이 나오지만

'3e10'같은경우에는 지수함수로 인식이되므로 하나하나 확인했다
