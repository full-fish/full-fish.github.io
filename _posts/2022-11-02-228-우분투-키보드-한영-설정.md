mx\_key alt\_R를 한영키로 바꿀때

해당 키가 Super\_R로 먹힐때도있고

ALT\_R로 먹힐때도 있다

Super\_R일때

```shell
sudo nano /usr/share/X11/xkb/symbols/pc
```

여기서 Super\_R을 Hangul로 바꾸기

ALT\_R일때

```shell
cd /usr/share/X11/xkb/symbols
sudo nano altwin
```
