**코드**

```javascript
function solution(s) {
  let sSplitArr = s.split(" ");
  for (let i = 0; i < sSplitArr.length; i++) {
    sSplitArr[i] = sSplitArr[i].toLowerCase().replace(/^[a-z]/, (x) => x.toUpperCase());
  }
  return sSplitArr.join(" ");
}
```
