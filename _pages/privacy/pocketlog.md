시행일: 2026년 10월 5일

Pocketlog(이하 "앱")는 내 휴대폰 안에서 돌아가는 가계부예요. 회원가입이 없고, 개발자는 이용자의 가계부 데이터를 모으는 서버를 두지 않아요. 이 방침은 앱이 어떤 정보를 어디에 두고, 언제 밖으로 보내는지 설명해요.

## 1. 휴대폰 안에만 저장하는 정보

다음 정보는 이용자의 휴대폰(앱 전용 저장 공간)에만 저장되고 개발자에게 전송되지 않아요.

- 직접 입력하거나 자동으로 기록한 내역: 금액, 날짜와 시각, 가맹점 이름, 카테고리와 태그, 결제수단, 메모, 할부 정보, 외화 금액
- 카테고리, 결제수단(카드사, 카드 끝 4자리, 이용자가 입력한 잔액), 예산, 즐겨찾기와 반복 기록, 자동 분류 규칙
- 결제 알림 원문: 카드·은행·페이 앱 알림과 문자 알림 중 **결제로 보이는 것만** 원문(보낸 앱, 제목, 내용, 받은 시각)을 저장해요. 기록이 맞는지 확인하고 다시 읽기 위해서예요.
- 스크린샷·영수증 사진: 분석에 쓴 이미지의 사본. 내역을 저장한 뒤에는 작은 썸네일로 줄이고, 저장하지 않은 분석은 30일 뒤 지워요.
- 월간 리포트 내용, 설정 값(내 이름, 한 달 시작일, 테마 등), 앱 잠금 PIN의 해시(PIN 자체는 저장하지 않아요)

## 2. 알림 접근 권한

자동 기록을 켜면 앱이 휴대폰의 알림을 읽어요.

- 모든 알림을 읽지만, 카드·은행·페이 결제로 보이지 않는 알림(메신저, 개인 문자 등)은 **저장하지 않고 바로 버려요.**
- 결제 알림에서 읽은 내용은 위 1번처럼 휴대폰 안에만 저장해요.
- 설정 → 자동 기록에서 언제든 끌 수 있고, 휴대폰 설정에서 알림 접근 권한을 거두면 더 이상 읽지 않아요.

## 3. 밖으로 보내는 경우

### AI 기능 (이용자가 동의한 경우에만)

설정 → AI 사용 동의를 켠 경우에만 아래 정보를 Pocketlog AI 서버로 보내요. 처음에는 꺼져 있어요.

| 기능 | 보내는 정보 |
| ---- | ---- |
| 스크린샷·영수증 분석 | 고른 이미지, 카테고리·태그 이름 목록, 이용자가 만든 분류 규칙 일부(가맹점 → 카테고리) |
| 알림 다시 읽기 | 앱이 스스로 읽지 못한 결제 알림의 제목과 내용 |
| 카테고리 자동 분류 | 처음 보는 가맹점 이름, 카테고리·태그 이름 목록 |
| 월간 리포트 | 한 달 합계: 카테고리·태그별 금액, 자주 간 곳(가맹점 이름, 횟수, 금액), 큰 지출 5건(가맹점, 금액, 날짜, 카테고리), 예산, 날짜별 합계 |

- AI 서버(Cloudflare Workers)는 받은 내용을 저장하지 않고 OpenAI API로 넘겨 결과만 돌려줘요. 서버에는 호출 경로, 사용한 모델, 사용량(토큰 수)만 기록돼요.
- OpenAI는 API로 받은 데이터를 학습에 쓰지 않고, 악용 감시를 위해 최대 30일 보관한 뒤 지워요(OpenAI API 데이터 정책).
- 이미지에 주소·이름처럼 보내고 싶지 않은 내용이 있으면 잘라서 보내 주세요.

### 환율

외화 결제를 원화로 바꿀 때 하루 한 번 환율 정보(open.er-api.com)를 받아요. 이 요청에는 이용자 정보가 들어가지 않아요.

### Google 드라이브 백업 (이용자가 고른 경우에만)

- 백업 파일은 이용자가 정한 비밀번호로 암호화한 뒤(AES-GCM) **이용자 본인의 Google 드라이브**에 올려요. 개발자는 이 파일에 접근할 수 없어요.
- 앱은 `drive.file` 권한만 받아서, 앱이 직접 만든 파일과 폴더만 볼 수 있어요.
- Google 계정 로그인과 동의는 Google Play 서비스가 처리해요. 앱은 Google 비밀번호를 받지 않아요.
- 매일 자동 백업을 위해 백업 비밀번호를 휴대폰의 보안 저장소(Android Keystore) 키로 암호화해 휴대폰 안에 보관해요.

### Android 기기 백업

휴대폰 설정에서 Google 백업이 켜져 있으면, Android가 앱 데이터(스크린샷 사본 제외)를 이용자의 Google 계정에 백업할 수 있어요. 이는 Google의 기기 백업 기능이에요.

## 4. 국외 이전

AI 기능을 켠 경우 위 3번의 정보가 아래처럼 국외로 전송돼요.

| 받는 곳 | 국가 | 목적 | 보관 |
| ---- | ---- | ---- | ---- |
| Cloudflare, Inc. (AI 서버 운영) | 미국 등 Cloudflare 데이터센터 | 요청 전달 | 저장하지 않음 |
| OpenAI, L.L.C. | 미국 | 이미지·문장 분석, 리포트 작성 | 최대 30일 (악용 감시) |

전송 시점은 해당 기능을 쓸 때이고, 암호화된 연결(HTTPS)로 보내요. AI 사용 동의를 끄면 더 이상 보내지 않아요.

## 5. 쓰지 않는 것

- 광고, 분석 도구, 오류 수집 도구를 쓰지 않아요.
- 회원가입, 로그인 서버, 이용자 데이터베이스가 없어요.
- 이용자 정보를 팔거나 다른 곳에 제공하지 않아요.

## 6. 권한

| 권한 | 쓰는 곳 |
| ---- | ---- |
| 알림 접근 | 결제 알림 자동 기록 |
| 알림 보내기 | 기록·예산·리포트 알림 |
| 인터넷 | AI 기능, 환율, Google 드라이브 백업 |
| 배터리 최적화 예외 요청 | 앱이 잠든 사이 결제 알림을 놓치지 않도록 |
| 생체 인증 | 앱 잠금을 지문·얼굴로 풀기 |
| 부팅 후 실행, 네트워크 상태 | 하루 한 번 작업(반복 기록, 월간 리포트, 자동 백업) |

사진은 Android 사진 선택기로, 촬영은 휴대폰의 카메라 앱으로 해서 사진·카메라 권한을 따로 받지 않아요.

## 7. 보관 기간과 삭제

- 휴대폰 안의 데이터는 이용자가 지울 때까지 보관해요. 설정 → 백업 · 복구 → 데이터 초기화, 또는 앱 삭제로 모두 지워져요.
- Google 드라이브의 백업 파일은 최근 5개만 남고, 이용자가 드라이브에서 직접 지울 수 있어요.

## 8. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않아요.

## 9. 변경

이 방침이 바뀌면 이 문서를 고치고 위 시행일을 바꿔요. 바뀐 내용은 저장소의 변경 기록에서 볼 수 있어요.
